## Expanded 2026 reference

- [FastAPI 2026 Master API Reference](fastapi-2026-master-reference.md)

**Reference baseline:** FastAPI 0.162.1 (11 November 2026), Python 3.11+, Pydantic v2.

The 2026 guide covers app and router APIs, `Annotated` request parameters, Pydantic v2 models, dependency injection, response filtering, exceptions, lifespan, middleware, OAuth2/API-key helpers, uploads, background tasks, WebSockets, SSE, JSON Lines, streaming responses, testing, CLI commands, and OpenTelemetry configuration.

The 3-page high-resolution PNG companion pack is supplied separately in the conversation because the connected GitHub file action can commit text files but cannot transmit binary PNG bytes. Add the three PNG files next to this README to keep the visual exports in this folder.
